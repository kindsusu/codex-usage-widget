# Codex Usage Widget 사용설명서

## 1. 소개

Codex(ChatGPT 계정)의 사용량 한도를 바탕화면 한구석에서 바로 확인하는 작은 Windows 위젯입니다.

![다크 테마 전체 카드](img/desktop-card-dark.png)

*시연 화면의 값은 5시간 72%, 주간 38% 예시입니다.*

![라이트 테마 전체 카드](img/desktop-card-light.png)

*시연 화면의 값은 5시간 72%, 주간 38% 예시입니다.*

한도 창(주간 / 5시간)은 **Codex가 실제로 알려준 것만** 표시합니다. 계정에 주간 한도만 있으면 주간 한 줄만, 5시간 한도까지 있으면 두 줄이 함께 나옵니다. 없는 항목을 임의로 만들어 보여 주지 않습니다.

---

## 2. 설치

### 전제조건

- Windows 10 또는 11
- Python 3.11 이상 (설치할 때 **"Add Python to PATH"** 체크)
- **Codex 데스크톱 앱(ChatGPT 앱) 또는 Codex CLI가 설치되어 있고, ChatGPT 계정으로 로그인되어 있을 것**
  - 위젯은 내 PC에서 돌아가는 Codex에 사용량을 물어보는 방식이라, Codex 로그인이 되어 있어야 숫자가 나옵니다.

### 설치 순서

1. 저장소를 내려받습니다(ZIP 다운로드 또는 `git clone`).
2. PowerShell에서 프로젝트 폴더를 열고 아래 두 줄을 실행합니다.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -e .
   ```

3. 설치가 끝나면 폴더 안의 **`실행.bat`을 더블클릭**하거나, 다음 명령으로 실행합니다.

   ```powershell
   .\.venv\Scripts\pythonw.exe widget.pyw
   ```

> `실행.bat`은 `.venv`가 있으면 자동으로 그걸 쓰고, 없으면 시스템 Python을 찾습니다. 필요한 패키지가 빠져 있으면 무엇을 설치해야 하는지 안내 메시지를 띄웁니다.

## 3. 화면 구성

### 제목 줄

| 요소 | 설명 |
|---|---|
| Codex 로고 | 카드의 식별 표시입니다. 기존 펫 설정 값은 보존하지만 이 카드에는 표시하지 않습니다. |
| 플랜 이름 | `Plus`처럼 계정 플랜이 표시됩니다. |
| 미니 모드 | 머리글의 버튼으로 미니 스트립으로 바꿉니다. |

### 사용량 줄

| 줄 | 의미 |
|---|---|
| **주간 한도** | 최근 7일(10080분) 기준 사용률입니다. |
| **5시간 한도** | 5시간(300분) 단위로 초기화되는 단기 한도입니다. 계정에 이 한도가 있을 때만 나타납니다. |

막대는 **남은 양**을 나타냅니다. 남은 양에 따라 테마별 초록·황갈색·빨강 상태를 쓰며, 색과 무관하게 정확한 백분율이 항상 숫자로 함께 표시됩니다.

초기화 시각과 현재 업데이트·이전 값·오류 상태는 작업표시줄 사용량을 왼쪽 클릭해 여는 상세 창에서 확인합니다. 크레딧이나 초기화권은 현재 카드나 상세 창에 표시하지 않습니다.

### 창 옮기기

빈 곳을 드래그하면 위젯이 따라오고, 마우스를 놓는 순간 위치가 저장됩니다.

## 4. 표시 설정과 고급 메뉴

작업표시줄 왼쪽 Codex 아이콘을 **왼쪽 클릭**하면 표시 설정 패널이 열립니다. 패널에는 아래 세 항목만 있으며 현재 조합도 함께 표시합니다.

![표시 설정 패널](img/visibility-panel-dark.png)

*시연 화면의 값은 5시간 72%, 주간 38% 예시입니다.*

| 메뉴 | 설명 |
|---|---|
| **바탕화면 위젯 표시** | 일반 바탕화면 카드를 표시하거나 감춥니다. |
| **바탕화면 미니 모드** | 바탕화면 카드를 244×46 미니 스트립으로 바꿉니다. |
| **작업표시줄 위젯 표시** | 작업표시줄 사용량 표시를 켜거나 끕니다. |

세 설정은 독립적으로 저장됩니다. 표시 상태는 **둘 다 표시**, **바탕화면만 표시**, **작업표시줄만 표시**, **둘 다 숨김**의 네 가지이며, 둘 다 숨겨도 트레이에서 복원할 수 있습니다.

왼쪽 Codex 아이콘을 **오른쪽 클릭**하면 고급 네이티브 메뉴가 열립니다. 여기서 새로고침, 테마, **투명도 값**, 배율, 종료를 고릅니다.

## 5. 작업표시줄 사용량 표시

작업표시줄의 알림 영역 앞 빈 공간을 우선 사용해 Codex가 실제로 알려 준 한도 창을 최대 두 줄로 표시합니다. 공간이 부족하면 시작 버튼 왼쪽의 검증된 빈 영역을 사용하되, 시스템 제어용 왼쪽 200 logical px는 항상 보호합니다. 각 줄은 **남은 비율**을 보이며, 서버가 주간·5시간 창을 모두 주면 두 줄, 하나만 주면 한 줄만 보입니다. 없는 한도 창을 임의로 만들지 않습니다.

- **왼쪽 클릭**: 실제 한도 행, 남은 비율, 초기화 시각과 업데이트·이전 값·오류 상태를 보여 주는 비모달 상세 창을 열거나 닫습니다.
- **왼쪽 Codex 아이콘 왼쪽 클릭**: 세 가지 표시 설정 패널을 엽니다.
- **왼쪽 Codex 아이콘 오른쪽 클릭**: 새로고침·테마·투명도·배율·종료를 위한 고급 네이티브 메뉴를 엽니다.
- 이 표시는 per-pixel alpha 표면으로 작업표시줄 내부에 표시되어 Windows 작업표시줄 재질이 보입니다. 호버 때만 부드러운 반투명 배경이 더해집니다.

이 기능은 Windows 11의 **주 모니터 가로 작업표시줄**을 대상으로 하며, 실제 Windows 라이브 검증 결과는 별도 보고합니다. Windows 10은 아직 실기기 검증하지 않았습니다. 세로 작업표시줄, 보조 모니터 작업표시줄, 지원하지 않는 셸 구성, Explorer가 다시 시작되는 중인 경우, 또는 알림 영역 앞과 시작 버튼 왼쪽의 검증된 영역 모두에 197 logical px 공간이 없는 경우에는 작업표시줄 표시를 붙일 수 없습니다. 이때 바탕화면 위젯을 잠시 보여 주어 다시 조작할 수 있게 하며, 사용자가 저장한 표시 설정은 바꾸지 않습니다. 작업표시줄 상태는 약 1.5초 간격으로 다시 찾고, 네이티브 작업자는 실패 뒤 약 10초 후 다시 시작합니다.

## 7. 트레이와 표시 복원

표시 설정 패널에서 바탕화면 카드를 숨겨도 작업표시줄 표시 설정은 그대로 유지됩니다. 프로그램은 시스템 트레이에서 계속 실행됩니다.

- 트레이 아이콘 **왼쪽 클릭** → `사용량 상세` 팝업
- 트레이 아이콘 **오른쪽 클릭** → `사용량 상세`, `바탕화면 위젯 표시`, `바탕화면 미니 모드`, `작업표시줄 위젯 표시`, `새로고침`, `종료`
- **완전히 끄려면** 트레이 메뉴의 `종료` 또는 위젯 우클릭 메뉴의 **종료**를 사용하세요.

> 일반 앱 창용 작업표시줄 버튼은 만들지 않습니다. 대신 내장 사용량 지표는 작업표시줄 내부에 표시될 수 있습니다. 보이지 않는다고 종료된 것이 아니니 트레이를 먼저 확인하세요.

## 8. 컴퓨터 켤 때 자동 실행하기

1. 키보드에서 **Win + R** 을 누릅니다.
2. `shell:startup` 을 입력하고 확인을 누르면 시작프로그램 폴더가 열립니다.
3. 이 폴더에 **바로가기**를 만들어 넣습니다.
   - 가장 간단한 방법: `실행.bat`을 마우스 오른쪽 버튼으로 끌어다 놓고 **[여기에 바로가기 만들기]** 를 고릅니다.
   - 직접 만들 경우 바로가기 속성을 다음과 같이 설정합니다.

     | 항목 | 값 |
     |---|---|
     | 대상 | `C:\경로\codex-usage-widget\.venv\Scripts\pythonw.exe "C:\경로\codex-usage-widget\widget.pyw"` |
     | 시작 위치 | `C:\경로\codex-usage-widget` |

4. 다음 부팅부터 자동으로 실행됩니다. 바탕화면·작업표시줄 표시, 미니 모드, 배율과 위치를 포함한 설정은 다음 실행에도 유지됩니다. 자동 실행을 끄려면 이 폴더에서 바로가기를 지우면 됩니다.

## 9. 문제 해결 (FAQ)

**Q. "Codex 사용량을 불러올 수 없습니다."가 떠요.**
Codex를 찾지 못했거나 실행할 수 없는 상태입니다. Codex 데스크톱 앱(ChatGPT 앱) 또는 Codex CLI를 설치한 뒤 위젯을 다시 실행하세요. 설치 위치가 특이하면 환경변수 `CODEX_EXE`에 `codex.exe`의 전체 경로를 지정하면 됩니다.

**Q. "Codex에 로그인한 뒤 다시 시도하세요."가 떠요.**
Codex 앱이나 CLI에서 ChatGPT 로그인을 완료한 다음, 위젯을 우클릭해 **새로고침**을 누르세요.

**Q. 사용량 줄이 하나밖에 없어요.**
정상입니다. 위젯은 서버가 돌려주지 않은 한도 창을 임의로 만들어 표시하지 않습니다. 계정에 주간 한도만 있으면 주간 한 줄만 나옵니다.

**Q. 트레이 아이콘이 안 보여요.**
일부 환경에서는 시스템 트레이를 쓸 수 없습니다. 이때도 위젯 자체와 고급 메뉴(종료 포함)는 정상 동작합니다. 트레이를 못 쓰는 상태에서는 두 표시 위치를 모두 숨기지 마세요.

**Q. 실행.bat을 눌러도 아무 반응이 없어요.**
구버전 위젯이 실행 중이면 전역 중복 실행 방지 때문에 새 버전 실행이 제한될 수 있습니다. 구버전의 트레이 메뉴에서 **종료**한 뒤 새 버전을 실행하세요. 이번 버전부터는 `실행.bat`을 다시 실행하면 이미 실행 중인 같은 버전의 데스크톱 위젯을 복원합니다. 시작 오류는 안내 창으로 알려 주며, 오류 종류만 `%LOCALAPPDATA%\CodexUsageWidget\startup.log`에 남습니다.

**Q. 실행은 된 것 같은데 위젯이 안 보여요.**
1. 먼저 트레이(작업표시줄 오른쪽 아래 ^ 아이콘)를 확인하고, 아이콘을 오른쪽 클릭해 **바탕화면 위젯 표시**를 누릅니다.
2. 그래도 안 보이면 모니터 구성이 바뀌면서 화면 밖 위치가 저장된 경우일 수 있습니다. 위젯을 종료하고 폴더의 `widget_config.json` 파일을 삭제한 뒤 다시 실행하면 기본 위치로 돌아옵니다. (테마·배율·펫 설정도 초기화됩니다.)

**Q. 다른 창을 클릭하면 위젯이 뒤로 숨어요.**
정상 동작입니다. **스마트 포지션 스위칭**이 켜져 있으면 위젯이나 Codex가 앞에 있을 때만 위로 올라옵니다. 항상 맨 위에 두고 싶으면 우클릭 메뉴에서 이 항목을 끄세요.

**Q. 작업표시줄 사용량 표시가 안 보여요.**
세로 작업표시줄, 보조 모니터 작업표시줄, 지원하지 않는 Windows 셸 구성, Explorer 전환 중이거나 아이콘 때문에 남은 공간이 부족한 경우일 수 있습니다. 이때는 바탕화면 위젯으로 계속 확인할 수 있고, 작업표시줄 표시 설정은 자동으로 꺼지지 않습니다. 주 모니터 작업표시줄을 가로로 두고 공간을 확보한 뒤 다시 확인하세요.

**Q. 실행이 안 되고 "Required packages are missing"이 떠요.**
설치 2단계(`.\.venv\Scripts\python.exe -m pip install -e .`)를 다시 실행하세요.

## 10. 데이터와 보안

- 위젯은 내 PC에서 도는 **Codex의 공식 `app-server` 프로세스**에 사용량(`account/rateLimits/read`)만 물어봅니다.
- Codex의 로그인 파일(`auth.json`)을 **직접 읽거나 수정하지 않습니다.**
- OAuth 토큰, 이메일, 사용자 ID, 계정 ID를 **저장하지도, 기록하지도, 화면에 표시하지도 않습니다.**
- 설정 파일(`widget_config.json`)에는 화면 설정(테마·투명도·배율·미니 모드·위치·펫·새로고침 간격·바탕화면/작업표시줄 표시)만 저장됩니다.
- 외부 서버로 따로 데이터를 보내는 기능은 없습니다. 사용량 조회는 내 PC 안에서 Codex를 통해서만 이루어집니다.
