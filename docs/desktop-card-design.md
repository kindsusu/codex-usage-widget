# 데스크톱 카드·표시 패널 시안 계약

승인 원본은 [taskbar-widget-design.html](taskbar-widget-design.html)의 전체 카드, 미니 스트립, `ct-tray-menu`다. 구현 및 실제 Windows 검증을 마쳤으며 [검수 결과](desktop-redesign-validation.md)에 동작과 렌더링 차이를 기록했다.

## 전체 카드

- 전체 카드는 `280 × 156` logical px, 16px 안쪽 여백, 1px 테두리, 14px 모서리를 사용한다. 호스트 기본 line-height는 1.75(28px)다.
- 승인 HTML 배경은 light `rgba(255,255,255,.94)`, dark `rgba(29,37,51,.96)`이고 `backdrop-filter: blur(18px)` 및 별개의 shadow가 있다. 실제 Tk 창은 단색 표면과 사용자의 기존 전체 창 투명도를 사용한다. CSS 배경 흐림·그림자·요소별 투명도는 재현하지 않으며, 테두리를 선합성해 흰색 halo를 방지한다.
- 머리글은 26px 정사각 Codex 로고(8px 모서리), `Codex` 14px semibold, 오른쪽 `Plus` 12px muted, 28px 높이의 `미니 모드` 버튼으로 구성한다. 요소 간격은 9px, 머리글 아래 여백은 15px이다.
- 각 한도 행은 12px 라벨·semibold 잔여 비율, 6px 둥근 막대로 표시한다. 행 안쪽의 라벨/값 간격은 12px, 값 아래 막대 간격은 6px, 다음 행 전 간격은 13px이다.
- 표시하는 것은 Codex가 실제로 준 한도 창뿐이며 비율은 잔여량이다. 펫 그림은 이 카드 시안에서 제거하되 기존 설정 값은 보존한다.

## 미니 스트립

- 미니 카드는 `244 × 46` logical px, 가로 8px·세로 7px 여백, 10px 모서리다.
- 배경은 light `rgba(255,255,255,.58)`, dark `rgba(20,27,39,.58)`이며, 그림자는 각각 `0 5px 18px rgba(29,43,65,.10)`·`rgba(0,0,0,.22)`이다.
- 14px Codex 로고 뒤에 8px 간격으로 한도 미터를 배치한다. 미터는 22px 라벨, 25px 막대, 25px 값과 3px 간격이며 막대는 높이 4px이다.
- 오른쪽에는 `28 × 28` 복원 버튼을 둔다. 전체 카드와 한도 행은 미니 모드에서 보이지 않는다.

### 미니모드 배율과 실측 크기

실제 창 크기는 기본 논리 크기에 Windows 화면 배율과 위젯의 미니 배율을 각각 한 번씩 곱한 뒤 정수 픽셀로 반올림한다.

| Windows 화면 배율 | 미니 배율 | 실제 크기 |
|---|---|---|
| 100% | 100% | 244 × 46px |
| 150% | 100% | 366 × 69px |
| 150% | 150% | 549 × 104px |

2026-09-14 실행 중인 미니 창을 조회해 DPI 144(Windows 150%), 미니 배율 150%, 실제 크기 **549 × 104px**를 확인했다. 이는 두 배율을 적용한 정상 크기다. Windows 150%에서 시안의 기본 미니 배율로 표시하려면 우클릭 → **미니 배율 → 100%**를 선택하면 **366 × 69px**가 된다. 이번 확인에서는 사용자 설정과 구현 코드를 변경하지 않았다.

## 표시 설정 패널

- 작업표시줄의 오른쪽 Codex 버튼 **왼쪽 클릭**은 고급 메뉴가 아니라 이 패널을 연다.
- 패널은 `292 × 218.25` logical px, 7px 여백, 1px 테두리, 12px 모서리, 불투명 surface 배경을 사용한다. 제목은 15px Codex 로고와 `Codex 사용량` 12px semibold, 8px 간격·가로 10px/세로 8px 여백이다.
- 체크 행은 최소 높이 40px, 안쪽 7px·9px, 7px 모서리, 13px 글자, 16px checkbox와 10px 간격이다. 호버는 공통 hover 색, checkbox accent는 green이다.
- 라벨은 정확히 `바탕화면 위젯 표시`, `바탕화면 미니 모드`, `작업표시줄 위젯 표시`를 사용한다. 아래 상태 문구는 11px muted로 `두 위치에 표시 중` 등 현재 조합을 설명한다.

## 상호작용과 상태

- 작업표시줄 사용량 영역 **왼쪽 클릭**은 기존처럼 상세를 열고 닫는다.
- 오른쪽 Codex 버튼 **왼쪽 클릭**은 위 표시 설정 패널을 연다. **오른쪽 클릭**은 기존 고급 네이티브 컨텍스트 메뉴(새로고침·테마·투명도·배율·종료)를 연다.
- 세 체크 상태는 데스크톱 표시·데스크톱 미니·작업표시줄 표시를 독립적으로 저장한다. 네 가지 가시 상태는 둘 다 표시, 데스크톱만 표시, 작업표시줄만 표시, 둘 다 숨김(트레이에서 복원)이다.
